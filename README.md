# 🤖 AIML SureTrust Training Journey

This repository documents my **Artificial Intelligence & Machine Learning (AIML) training journey at SureTrust**.  
It includes **DSA assignments, hands-on machine learning practice, and applied notebooks** created during structured training sessions.

The repository serves both as:
- 📘 **Training coursework record**
- 💼 **Portfolio showcase** for recruiters and evaluators

---

## 🎯 Objectives
- Build strong foundations in **Data Structures & Algorithms (DSA)**
- Apply **machine learning concepts** to practical datasets
- Gain hands-on experience with **data preprocessing, modeling, and evaluation**
- Develop industry-relevant analytical and problem-solving skills

---

## 🧠 Key Skills & Concepts Covered
- Data Cleaning & Preprocessing  
- Sliding Window & Time-Series Analysis  
- Frequency Analysis & Hash Maps  
- Correlation & Feature Selection  
- Linear Regression  
- K-Nearest Neighbors (KNN)  
- Model Evaluation (RMSE, MAE, R²)  
- Bias–Variance Trade-off
