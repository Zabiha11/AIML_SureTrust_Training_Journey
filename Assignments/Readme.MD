## ✅ DSA 4: House Price Estimation & Buyer Segmentation  
**(Regression & Classification – Linear Regression & KNN)**

### 🏢 Industry Context
A real estate analytics firm aims to:
- Predict house prices
- Segment buyers based on purchasing behavior

---

### Part A: House Price Prediction (Linear Regression)
- Used features such as area, number of bedrooms, location score, and age of property
- Performed exploratory data analysis and validated Linear Regression assumptions
- Built a Linear Regression model for price prediction
- Evaluated model performance using:
  - RMSE
  - MAE
  - R² Score
- Interpreted model coefficients and explained business implications

---

### Part B: Buyer Segmentation (KNN Classification)
- Classified buyers into segments using customer attributes:
  - Budget
  - Purchase frequency
  - Preferred location
- Implemented a K-Nearest Neighbors (KNN) classifier
- Experimented with different values of K and distance metrics
- Applied cross-validation to determine the optimal K
- Explained the bias–variance trade-off in KNN
- **Bonus:** Visualized decision boundaries using selected features

**Key Concepts:**  
`Linear Regression`, `KNN`, `Model Evaluation`, `Bias-Variance Tradeoff`, `Classification`
