# 📘 Machine Learning – In-Class Practice Work

This repository contains in-class machine learning practice work completed on different days.  
The focus is on understanding core machine learning concepts, algorithms, and data preprocessing techniques using real-world and synthetic datasets.

---

## 📂 List of Experiments & Datasets

### 1. Exploratory Data Analysis (EDA)
- **Dataset:** Seoul Bike Data (`Seoul Bike Data.csv`)
- Data cleaning and preprocessing
- Univariate and multivariate analysis
- Visualization of trends and correlations
- Feature understanding and insights

---

### 2. Logistic Regression – Pulsar Star Classification
- **Dataset:** Pulsar Star Data Train (`Pulsar Star Data Train.csv`)
- Binary classification problem
- Feature scaling and preprocessing
- Logistic Regression model
- Model evaluation using accuracy and confusion matrix

---

### 3. Logistic Regression – Heart Disease Prediction
- **Dataset:** Heart Disease Dataset
- Medical classification task
- Data preprocessing and feature analysis
- Logistic Regression implementation
- Performance evaluation

---

### 4. KNN & Logistic Regression with Encoding
- **Dataset:** Weather Classification Data
- Applied Label Encoding and OneHot Encoding
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Comparison of model performance

---

### 5. K-Nearest Neighbors Regressor
- **Dataset:** Financial Regression Dataset
- Regression problem
- Feature scaling
- KNN Regressor implementation
- Model evaluation

---

### 6. Support Vector Machine (SVM)
- **Dataset:** Synthetic Dataset
- SVM using built-in libraries
- Understanding margin and kernel concepts
- Model visualization and evaluation

---

### 7. SVM and KNN from Scratch
- **Dataset:** Synthetic Dataset
- Implemented SVM from scratch
- Implemented KNN from scratch
- Focus on understanding algorithm internals

---

### 8. Markov Decision Process (MDP)
- Solved **30 MDP questions**
- Focus on understanding:
  - States, actions, rewards
  - Policy and value functions
  - Bellman equations

---

### 9. Movie Recommendation System
- **Dataset:** MovieLens (`ml-latest-small`)
- Worked with 4 different datasets:
  - Movies
  - Ratings
  - Tags
  - Links
- Understanding relationships between datasets
- Basic recommendation system concepts
